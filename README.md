# FabricBootstrap

Lightweight Fabric bootstrap utilities for Minecraft **1.21.4**.

## Release

Download the latest JAR from [Releases](https://github.com/hodboy/FabricBootstrap/releases).

| File | Minecraft | Version |
|------|-----------|---------|
| `wayfinder-fabric-mc1.21.4-1.0.0.jar` | 1.21.4 (Fabric) | 1.0.0 |

## Usage

Requires **Java 21+** on Windows.

```bat
java -jar wayfinder-fabric-mc1.21.4-1.0.0.jar
```
